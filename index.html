导入说明

下载 JSON 后，在对应切片软件中导入线材预设即可使用。

  1. 选择切片器并筛选所需材料 / 机型。
  2. 下载单个 JSON，或勾选多项打包 ZIP。
  3. 在切片软件中打开「导入预设 / Import Config」，选择文件。
